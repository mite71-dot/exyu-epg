# EX-YU EPG

Daily XMLTV guide for my EX-YU playlist: epgshare01 (RS1, HR1, BA1, SPORTKLUB1) filtered to the playlist's channels, plus Macedonian channels grabbed from maxtvgo.mk with [iptv-org/epg](https://github.com/iptv-org/epg).

EPG URL: `https://raw.githubusercontent.com/mite71-dot/exyu-epg/epg/epg.xml.gz`

Updated every day at 03:17 UTC by GitHub Actions.
